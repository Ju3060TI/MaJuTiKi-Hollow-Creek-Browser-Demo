# Hollow Creek — Demo

A quiet first-person voxel game set in a secluded Appalachian valley.
Built with Three.js. Single HTML file. No install. Just open and walk.

---

## About

You are a son returning to your deceased father's old cabin. There are no quests, no combat, and no hunger. The valley is yours to wander, to dig, to reshape, and to understand.

The cabin still has warm light in the window. A dirt path leads into the forest and up the ridge to a half-collapsed 1950s fire watchtower. On top of the tower, a rusted logbook, a pair of binoculars, and a hand-drawn map wait with three marked spots.

The father watched this valley from the tower. The son came back to understand why.

---

## Features

- Smooth voxel terrain (Surface Nets isosurface meshing)
- Dynamic chunk streaming around the player
- Terraforming: left-click digs, right-click places
- Appalachian autumn atmosphere: dense fog, muted greens, reds and oranges
- Day cycle (15 real minutes = 13 in-game hours)
- Procedural audio: wind, river, birds, branches (Web Audio API)
- First-person controller with gravity, jumping, and slope collision
- Backpack inventory with weight system (Green Hell style)
- Story items: logbook, binoculars, hand-drawn map
- Hand-built landmarks: cabin, campfire, watchtower, fallen tree ramp

## Controls

| Key | Action |
|-----|--------|
| W A S D | Move |
| Mouse | Look around |
| Space | Jump |
| Left Click | Dig |
| Right Click | Place |
| TAB | Open / close backpack |
| E | Pick up nearby item |
| F | Raise / lower binoculars |

---

## How to Run

1. Save the file as `index.html`.
2. Open it in a modern browser (Chrome, Firefox, Edge, Safari).
3. Click the splash screen to begin.
4. Requires an internet connection (Three.js is loaded from a CDN).
